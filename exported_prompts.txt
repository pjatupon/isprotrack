## Required Ingestion Pipeline


สร้างหรือปรับปรุงฟังก์ชันให้ทำงานตามลำดับนี้:


1. ตรวจ session และ RBAC ด้วย `requireKnowledgeAccess()`
2. Validate title, category, document type และไฟล์
3. รองรับ PDF, JPEG, PNG และ WebP ขนาดไม่เกิน 15 MB
4. ตรวจชนิดไฟล์จาก magic bytes ห้ามเชื่อ MIME type หรือ extension จาก client
5. สร้าง SHA-256 checksum และป้องกันไฟล์ซ้ำ
6. บันทึก `KnowledgeDocument` ด้วยสถานะ `PROCESSING`
7. ส่ง PDF หรือภาพให้ AI Vision/OCR ผ่าน OpenRouter
8. สกัดข้อความภาษาเดิมโดยรักษาหัวข้อ ตาราง เลขข้อ ลำดับ และเลขหน้า
9. ห้ามให้ AI สรุป เติม หรือแต่งข้อมูลจากเอกสาร
10. Normalize ข้อความและแบ่งเป็น semantic chunks
11. Chunk ต้องมี overlap ที่เหมาะสมและไม่ตัดกลางหัวข้อหรือข้อกำหนด
12. เก็บ `pageNumber` และ `section` เมื่อระบุได้
13. ส่ง chunks ไปสร้าง embeddings แบบ batch
14. ตรวจจำนวน vector, dimensions และค่าตัวเลขทุกตัวก่อนบันทึก
15. บันทึก chunks และ vector ใน Prisma transaction
16. เก็บ vector ด้วย `JSON.stringify(vector)` ใน `KnowledgeChunk.embedding`
17. บันทึก `embeddingModel`, `dimensions` และ `extractedText`
18. เปลี่ยนสถานะเป็น `READY` เมื่อทุกขั้นตอนสำเร็จ
19. หากล้มเหลวให้เปลี่ยนเป็น `FAILED` และบันทึกข้อความใน `processingNote`
20. ห้ามปล่อยข้อมูล chunks บางส่วนค้างอยู่เมื่อ transaction ล้มเหลว


แยก business logic ออกจาก Server Action เป็น server-only services ที่ทดสอบได้ เช่น:

## AI Vision and OpenRouter


ใช้ configuration เดิมจาก `libs/openRouterAI.ts` และระบบ AI settings ที่มีอยู่ ห้าม hard-code API key


ต้องรองรับ:


- PDF ผ่าน OpenRouter file input และ file-parser/OCR ที่รองรับ
- JPEG, PNG, WebP ผ่าน `image_url` แบบ data URL
- `temperature: 0`
- Prompt ภาษาไทยที่กำชับให้ถอดข้อความเท่านั้น
- timeout ด้วย `AbortController`
- HTTP error, malformed response, rate limit และ empty content
- ข้อความ error สำหรับผู้ใช้ต้องอ่านเข้าใจได้ แต่ห้ามเปิดเผย API key หรือ response ที่ sensitive
- จำกัดจำนวนหน้า/token และแจ้งข้อผิดพลาดเมื่อเอกสารใหญ่เกินความสามารถ


Environment ที่ต้องใช้หรือรองรับ:


- `OPENROUTER_API_KEY`
- `OPENROUTER_API_URL`
- `OPENROUTER_MODEL`
- `OPENROUTER_EMBEDDING_MODEL`


ห้าม log API key, base64 file หรือข้อความเอกสารทั้งหมด


## File Storage


สร้างชื่อไฟล์ด้วย UUID และเก็บ original filename เฉพาะ metadata ป้องกัน path traversal ทุกจุด


ถ้าใช้ `public/media/rag` ตามระบบเดิม ต้องตรวจ path ด้วย `path.resolve()` ก่อนอ่านหรือลบ อย่างไรก็ตามเอกสารองค์กรไม่ควรถูกเปิดแบบ public โดยไม่มี authorization หากทำได้โดยไม่ขยาย scope มากเกินไป ให้ย้ายไป private storage และสร้าง protected download route ที่ตรวจ session/RBAC ก่อนส่งไฟล์


เมื่อ DB create ล้มเหลวต้องลบไฟล์ที่เพิ่งเขียน และเมื่อลบเอกสารให้จัดการไฟล์กับ DB อย่างปลอดภัยโดยใช้ quarantine/restore pattern เดิม


## Vector Retrieval


ปรับปรุง `retrieveKnowledge(query, limit)` ให้:


- Validate และจำกัดความยาว query
- สร้าง query embedding ด้วย model เดียวกับ document chunks
- เลือกเฉพาะ document สถานะ `READY`
- ไม่ใช้ document สถานะ `ARCHIVED`, `FAILED` หรือ `PROCESSING`
- เลือกเฉพาะ category ที่ active
- ตรวจ dimensions และ embedding model ให้ตรงกัน
- Parse JSON vector อย่างปลอดภัย
- คำนวณ cosine similarity
- กำหนด similarity threshold จาก config
- จำกัดจำนวนผลลัพธ์และคืน source metadata
- คืน `documentTitle`, `categoryName`, `documentType`, `pageNumber`, `section`, `content`, `similarity` และ authorized file URL
- ป้องกันการโหลดทุก vector จาก DB จน memory สูงเกินไป เช่น candidate limit, pagination หรือแนวทางที่เหมาะกับ MariaDB ปัจจุบัน
- หาก MariaDB รองรับ native vector อย่างยืนยันได้ ให้เสนอแผน migration แยกต่างหากก่อน ห้ามเปลี่ยน schema โดยพลการ


## Retry, Archive, Delete, and Reindex


- Retry ต้องอ่านไฟล์เดิม ประมวลผลใหม่ และแทนที่ chunks ใน transaction
- Archive ต้องทำให้ retrieval หยุดใช้เอกสาร แต่ยังเก็บไฟล์และ vector
- Restore ต้องนำเอกสารกลับมาใช้โดยไม่สร้าง vector ใหม่หากข้อมูลยังสมบูรณ์
- Delete ต้องมี confirmation และลบ `KnowledgeChunk` ผ่าน cascade
- Reindex ต้องสร้าง embeddings ใหม่เมื่อ embedding model เปลี่ยน
- ป้องกัน concurrent processing เอกสารเดียวกัน
- การ retry/reindex ล้มเหลวต้องไม่ทำลาย vector ชุดเดิมที่ยังใช้งานได้

## Required Ingestion Pipeline


สร้างหรือปรับปรุงฟังก์ชันให้ทำงานตามลำดับนี้:


1. ตรวจ session และ RBAC ด้วย `requireKnowledgeAccess()`
2. Validate title, category, document type และไฟล์
3. รองรับ PDF, JPEG, PNG และ WebP ขนาดไม่เกิน 15 MB
4. ตรวจชนิดไฟล์จาก magic bytes ห้ามเชื่อ MIME type หรือ extension จาก client
5. สร้าง SHA-256 checksum และป้องกันไฟล์ซ้ำ
6. บันทึก `KnowledgeDocument` ด้วยสถานะ `PROCESSING`
7. ส่ง PDF หรือภาพให้ AI Vision/OCR ผ่าน OpenRouter
8. สกัดข้อความภาษาเดิมโดยรักษาหัวข้อ ตาราง เลขข้อ ลำดับ และเลขหน้า
9. ห้ามให้ AI สรุป เติม หรือแต่งข้อมูลจากเอกสาร
10. Normalize ข้อความและแบ่งเป็น semantic chunks
11. Chunk ต้องมี overlap ที่เหมาะสมและไม่ตัดกลางหัวข้อหรือข้อกำหนด
12. เก็บ `pageNumber` และ `section` เมื่อระบุได้
13. ส่ง chunks ไปสร้าง embeddings แบบ batch
14. ตรวจจำนวน vector, dimensions และค่าตัวเลขทุกตัวก่อนบันทึก
15. บันทึก chunks และ vector ใน Prisma transaction
16. เก็บ vector ด้วย `JSON.stringify(vector)` ใน `KnowledgeChunk.embedding`
17. บันทึก `embeddingModel`, `dimensions` และ `extractedText`
18. เปลี่ยนสถานะเป็น `READY` เมื่อทุกขั้นตอนสำเร็จ
19. หากล้มเหลวให้เปลี่ยนเป็น `FAILED` และบันทึกข้อความใน `processingNote`
20. ห้ามปล่อยข้อมูล chunks บางส่วนค้างอยู่เมื่อ transaction ล้มเหลว


แยก business logic ออกจาก Server Action เป็น server-only services ที่ทดสอบได้ เช่น:


- `validateKnowledgeFile()`
- `storeKnowledgeFile()`
- `extractDocumentText()`
- `chunkKnowledgeText()`
- `generateEmbeddings()`
- `processKnowledgeDocument()`
- `retryKnowledgeDocument()`
- `retrieveKnowledge()`


Server Action ควรทำเพียง authorization, input parsing, เรียก service และ `revalidatePath`

const AI_REQUEST_TIMEOUT_MS = 120_000;


async function fetchWithTimeout(url: string, init: RequestInit, timeoutMs: number = AI_REQUEST_TIMEOUT_MS): Promise<Response> {
    const controller = new AbortController();
    const timer = setTimeout(() => controller.abort(), timeoutMs);
    try {
        return await fetch(url, { ...init, signal: controller.signal });
    } finally {
        clearTimeout(timer);
    }
}


function isAbortError(error: unknown): boolean {
    return error instanceof Error && (error.name === "AbortError" || error.message.includes("aborted"));
}

async function parseOpenRouterResponse(response: Response) {
    if (!response.ok) {
        const errorData = await response.json().catch(() => ({}));
        console.error(`OpenRouter API error: ${response.status}`, errorData);


        if (response.status === 401) {
            throw new Error('Invalid API Key - please check OPENROUTER_API_KEY or OPENAI_API_KEY');
        } else if (response.status === 403) {
            const message = errorData?.error?.message || '';
            if (message.includes('limit exceeded') || message.includes('Key limit')) {
                throw new Error('OpenRouter key limit exceeded - please check your quota or billing');
            }
            throw new Error('OpenRouter API access denied - please check your key permissions');
        } else if (response.status === 429) {
            throw new Error('Rate limit exceeded - please try again later');
        } else if (response.status === 500) {
            throw new Error('OpenRouter API server error - please try again later');
        }


        throw new Error(`OpenRouter API error: ${response.status} ${response.statusText}`);
    }


    const data = await response.json();


    if (!data.choices || !data.choices[0] || !data.choices[0].message) {
        console.error('Unexpected API response format:', data);
        throw new Error('Invalid response format from AI API');
    }


    const content = data.choices[0].message.content;


    if (!content) {
        throw new Error('AI returned empty response');
    }


    return content;
}


function extractJsonObject(text: string): string {
    const start = text.indexOf('{');
    const end = text.lastIndexOf('}');


    if (start === -1 || end === -1 || start >= end) {
        throw new Error('AI did not return valid JSON');
    }


    return text.slice(start, end + 1);
}


export async function generateText(
    prompt: string,
    options: AIGenerationOptions = {}
): Promise<string> {
    const settings = await getResolvedAiSettings();
    const { apiKey, model: defaultModel, apiUrl } = settings;


    const {
        model = defaultModel,
        temperature = 0.7,
        maxTokens = 2000,
    } = options;


    try {
        const response = await fetchWithTimeout(apiUrl, {
            method: 'POST',
            headers: getBaseHeaders(apiKey),
            body: JSON.stringify({
                model: model,
                messages: [
                    {
                        role: 'user',
                        content: prompt,
                    },
                ],
                temperature: temperature,
                max_tokens: maxTokens,
            }),
        });


        return await parseOpenRouterResponse(response);
    } catch (error) {
        if (isAbortError(error)) {
            throw new Error('AI ตอบสนองช้าเกินไป กรุณาลองใหม่อีกครั้ง');
        }


        console.error('AI Generation Error:', error);
        
        if (error instanceof Error) {
            if (error.message.includes('fetch failed')) {
                throw new Error('Network error - unable to connect to AI service');
            }
            throw error;
        }
        
        throw new Error('An unexpected error occurred during AI generation');
    }
}


export async function generateTextWithRetry(
    prompt: string,
    options: AIGenerationOptions = {},
    maxRetries: number = 2
): Promise<string> {
    let lastError: Error | null = null;
    
    for (let attempt = 0; attempt <= maxRetries; attempt++) {
        try {
            return await generateText(prompt, options);
        } catch (error) {
            lastError = error instanceof Error ? error : new Error(String(error));
            
            if (
                lastError.message.includes('Invalid API Key') ||
                lastError.message.includes('Invalid response format')
            ) {
                throw lastError;
            }
            
            if (attempt < maxRetries) {
                const delayMs = Math.pow(2, attempt) * 1000;
                await new Promise(resolve => setTimeout(resolve, delayMs));
            }
        }
    }
    
    throw lastError || new Error('Failed to generate text after retries');
}

export async function generateEmbeddings(input: string[]): Promise<EmbeddingBatch> {
    if (!input.length) {
        return { model: DEFAULT_OPENROUTER_EMBEDDING_MODEL, vectors: [] };
    }


    const settings = await getResolvedAiSettings();
    const model = process.env.OPENROUTER_EMBEDDING_MODEL || DEFAULT_OPENROUTER_EMBEDDING_MODEL;
    const response = await fetchWithTimeout(resolveEmbeddingsUrl(settings.apiUrl), {
        method: "POST",
        headers: getBaseHeaders(settings.apiKey),
        body: JSON.stringify({ model, input, encoding_format: "float" }),
    });


    if (!response.ok) {
        const errorData = await response.json().catch(() => ({}));
        console.error(`OpenRouter embedding error: ${response.status}`, errorData);
        throw new Error(`ไม่สามารถสร้าง vector ได้ (${response.status})`);
    }


    const data = await response.json() as {
        data?: Array<{ embedding?: number[]; index?: number }>;
        model?: string;
    };
    const vectors = [...(data.data ?? [])]
        .sort((left, right) => (left.index ?? 0) - (right.index ?? 0))
        .map((item) => item.embedding)
        .filter((embedding): embedding is number[] => Array.isArray(embedding));


    if (vectors.length !== input.length) {
        throw new Error("AI ส่ง vector กลับมาไม่ครบถ้วน");
    }


    const dimensions = vectors[0]?.length ?? 0;
    const isValid = dimensions > 0 && vectors.every(
        (vector) => vector.length === dimensions && vector.every((value) => typeof value === "number" && Number.isFinite(value)),
    );
    if (!isValid) {
        throw new Error("AI ส่ง vector ที่ไม่ถูกต้อง (ขนาดหรือค่าผิดปกติ)");
    }


    return { model: data.model || model, vectors };
}
